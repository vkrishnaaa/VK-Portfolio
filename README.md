# 💻 Personal Portfolio Website

My **personal portfolio website** is a frontend project created to introduce myself, showcase my skills, and present the projects I’ve been building while learning web development.

Unlike my previous projects, which were based around different concepts and themes, this project is focused on **me as a developer** — my learning journey, interests, skills and the work I’ve created so far.

## ✨ About the Project

The main purpose of this portfolio is to create a single place where I can showcase my work and gradually update it as I continue learning and building more projects.

I wanted the design to be simple, clean and easy to navigate while still having enough visual elements to make the website feel personal rather than like a basic template.

The portfolio brings together different sections to give visitors an idea of who I am, what I'm learning, and what I've been working on.

## 🧩 Main Sections

The website is structured around the important parts of a developer portfolio, including:

* 👋 **Introduction** — A quick introduction about me and what I'm currently working towards.
* 🧠 **Skills** — Technologies and skills that I'm currently learning and practicing.
* 🚀 **Projects** — A collection of the projects I've created while learning frontend development.
* 📖 **About Me** — More information about my background and development journey.
* 📬 **Contact** — A way for visitors to connect with me.
* 🔗 **Social Links** — Links to my professional profiles and development platforms.

## 🎨 Design & Styling

While building the portfolio, I focused on creating a layout that feels **clean, organized and personal**.

I experimented with:

* Page layouts and section organization
* Typography
* Colours and backgrounds
* Navigation
* Buttons and links
* Spacing and alignment
* Cards and content sections
* Hover effects
* Responsive design
* Visual hierarchy

One of the main things I wanted to improve was making different sections feel connected instead of looking like separate blocks placed on a page.

## 🧠 What I Learned

Building a personal portfolio was different from building a themed website because I had to think about **how to present myself and my work**, not just how to design a webpage.

This project helped me understand the importance of:

* Keeping information organized
* Creating clear navigation
* Designing around the user
* Maintaining consistency throughout a website
* Choosing what information is actually worth displaying
* Presenting projects in a simple and understandable way

It also made me realize that a portfolio isn't really a finished project. As I learn new technologies and build better projects, the portfolio can continue to evolve with me.

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

The website was created while I was learning the fundamentals of frontend development, without relying on frameworks.

## 🎯 Purpose of the Project

The main purpose of this project was to create my own online space where I could **showcase my development journey and projects**.

It also gave me an opportunity to apply the HTML and CSS concepts I had learned from my previous projects to something more personal and meaningful.

Rather than just building another practice webpage, I wanted to create something that I could actually continue improving as I progress as a developer.

## 🚀 What's Next

This portfolio is not the final version.

As I continue learning, I plan to improve it with new projects, better designs and more technologies.

My current goal is to strengthen my **HTML and CSS fundamentals**, move into **JavaScript**, and eventually explore **React and Full-Stack Development**.

This portfolio will grow along with that journey.
